# 🎢 Theme Park Website

A modern, highly responsive static web application designed to showcase theme park attractions, handle visitor ticketing calculations, and display real-time ride schedules. Built with a lightweight, front-end-only architecture, the site offers zero-latency page loads and fully responsive layouts across mobile, tablet, and desktop viewports.

## 🚀 Features

- **Responsive Landing Page:** Implements an intuitive user interface showcasing park highlights, maps, and current ticket prices.
- **Dynamic Ticket Price Calculator:** Built with native JavaScript to instantly compute total booking fees based on adult, child, and promotional ticket counts without page reloads.
- **Interactive Ride Status:** Displays a clean operational grid (e.g., Active, Maintenance, Closed) filtering out current park schedule information.
- **Optimized Layout Grid:** Uses Bootstrap's responsive grid system to ensure seamless user experiences across all screen sizes.

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3, Bootstrap 5 (Responsive Framework)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Hosting/Deployment:** Optimized for static hosting (Vercel)
